3. **`eligible_digital_assessment_coverage`:** كل مهارة قابلة للتصحيح الرقمي لها `QuestionFamily + Renderer + Grader + IndependentVerifier` مُمكّنة ومقاسة؛ الأنشطة اليدوية لها `TEACHER_REVIEW_REQUIRED` بدليل، ولا تُحسب تصحيحًا آليًا.
4. **`evidence_completeness`:** كل عنصر من عناصر المصدر له موقع PDF (بصمة/صفحة) ومعرّف، ورابط إلى artifact ومراجع اختبار وحالة مراجعة وCheckpoint موثَّق في GitHub.

```text
semantic_parity_percent = verified_equivalent_source_elements / all_identified_source_elements * 100
source_inventory_percent = inventoried_source_elements / all_source_elements_in_verified_editions * 100
digital_percent = verified_digital_skill_targets / eligible_digital_skill_targets * 100
evidence_percent = fully_evidenced_elements / all_identified_source_elements * 100
```

**ممنوع** حذف `SOURCE_UNAVAILABLE`, `SOURCE_CONFLICT`, `RIGHTS_RESTRICTED`, `MISMATCH_BLOCKED` من المقام للادعاء بـ100%. عند عدم توفر آخر كتاب طالب لازم تكون الحالة `DENOMINATOR_INCOMPLETE` والنسبة **UNKNOWN**، مهما بلغ عدد الدروس المسجلة. كما أن اكتمال كل عناوين فهرس محلي أقدم لا يثبت اكتمال عناصر الطبعة المستهدفة أو أهدافها أو صورها وأسئلتها.

**الحقوق واعتماد المالك:** تُستخدم الكتب الرسمية لتحديد التغطية والتسلسل؛ يُؤلّف الشرح والأمثلة والرسومات داخل Edulytics بصورة أصلية، ولا تُنشر نصوص أو صور الناشر المحمية بلا ترخيص. توثيق مرجع المصدر داخليًا لا يُساوي نسخ المحتوى، وتُحفظ أي متطلبات إسناد ذات صلة. قرار مالك البرنامج بالاعتماد والموافقة على نشر المحتوى المؤلف في Edulytics وارد في التكليف؛ يُسجّل دون تعطيل كل درس لطلب موافقة جديدة. لا يُذكر اسم ناشر المرجع في واجهة الطالب بوصفه مؤلفًا لمحتوى Edulytics. تشابه الأهداف والمفاهيم الرياضية لا يمنح حق نسخ صورة أو نص محمي؛ تبقى حالة الحقوق الداخلية مميّزة عن الاعتماد الأكاديمي ونتائج الاختبارات.
