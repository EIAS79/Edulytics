6.1 ? Dog Run

Sketch distance from home versus time for a dog that runs away for 3 minutes, waits 2 minutes, then returns faster than it left.

6.2 ? Which Graph is It?

Choose among four qualitative graphs for a story: start at 0, increase steadily, pause, then decrease to 0. Defend the choice using intervals.

6.3 ? Sketching a Story about a Boy and a Bike

Create a time-versus-distance graph for a rider who leaves home, stops at a store, continues farther, then returns. Label four anchor points and explain what each means.

Independent aligned practice (4 source problems reviewed)

Draw a second graph of the same story using distance traveled rather than distance from home; explain why the shapes differ.

Identify which quantity is a function of which in each graph.
