2.1 ? Square Me

Use f(x)=x? to make a mapping for -3,-1,0,1,3. Explain why two different inputs may share the same output without violating the function rule.

2.2 ? You Know This, Do You Know That?

For each relation, decide whether knowing the input determines exactly one output. Include a person's birth date, a student's locker number, and a relation with one input paired to two outputs.

2.3 ? Using Function Language

Write two context sentences in the form 'the output is a function of the input' and identify domain restrictions.

2.4 ? Same Function, Different Rule?

Show that 2(x+3)-6 and 2x define the same function for all real x. Give a counterexample pair of formulas that agree at one input but are not the same function.
