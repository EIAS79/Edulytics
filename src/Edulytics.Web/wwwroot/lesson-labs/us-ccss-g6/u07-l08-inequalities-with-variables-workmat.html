Writing Inequalities

First-party Edulytics learning activity. Numerical examples are precise; student-created diagrams and explanations receive teacher review.

8.1–8.2 • Inequality boundaries

All books cost less than5dollars: p<5. A5-dollar book is excluded, while4.99 is allowed. For cents,4.99 is the maximum; for arbitrary real prices there is no largest value below5.

8.3 • Measurement vs count

Homework beginning before7pm and ending after8pm lasts more than1hour. It might last less than2hours or longer than2hours. Mark the possible durations on a number line, and explain why they form an open-ended interval.

Independent Edulytics Cool-down

A box can contain fewer than8 whole paper clips. Write an inequality for n and list possible nonnegative whole-number quantities. Draw the number line.
