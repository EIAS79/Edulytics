Drawing Polygons on the Coordinate Plane

First-party Edulytics learning activity. Numerical examples are precise; student-created diagrams and explanations receive teacher review.

15.1 • Plot a rectangle with signed values

Plot(3,0),(3,-5),(-4,-5),(-4,0) in order. Show horizontal length7 and vertical length5, so perimeter24 and area35. Use a number line to explain the difference across zero.
