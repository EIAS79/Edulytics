Representing Distributions with Dot Plots

First-party Edulytics learning activity. Numerical examples are precise; student-created diagrams and explanations receive teacher review.

3.1–3.2 • Collect numerical observations

Estimate a teacher-drawn length, then record all classmates' estimates in inches. A frequency table tells how many times each estimate appears; its dot plot uses one dot for each observation.

3.4 • Choose a representation

Numerical counts, lengths and weights can be placed on a numeric axis in a dot plot. Sport preferences are categories; represent them using a labeled bar graph instead. Explain why two categories should not be averaged as numerical values.
