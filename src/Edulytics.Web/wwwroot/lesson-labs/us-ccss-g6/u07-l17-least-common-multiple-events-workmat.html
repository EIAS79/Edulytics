17.3 • Match items in packages

Cups come8 per package and napkins12 per package. The first equal total is24 items:3 cup packs and2 napkin packs. Compare with later shared multiples48 and72 to explain why24 is least.

17.4 • Multiples in context

Create a time line for activities repeating every12 and9 minutes. Their first coincidence is36 minutes, their second72. Give another event with a different LCM and justify which multiples are common.

Independent Edulytics Cool-down

Two buses depart the same stop now. Bus A returns every9 minutes, and Bus B every12 minutes. When will both return together for the first time? Explain using lists of multiples.

Teacher rubric: LCM(9,12)=36minutes. Teacher checks shared multiples and why no earlier positive time works. Automatic Practice checks selected numbers only. Teacher verifies learners' diagrams, scale, annotations, units and verbal justifications separately.
