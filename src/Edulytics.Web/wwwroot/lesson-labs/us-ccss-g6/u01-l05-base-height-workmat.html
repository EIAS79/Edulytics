5.3 — Four source-mechanic grid figures

Each grid step is one unit. Identify a side as the base and mark the perpendicular distance to the opposite parallel side. A base need not be horizontal. Enter the area of each figure in square units.

5.2 — Choosing a valid height

Classify these statements and explain why: Any side can be a base. A corresponding height must meet its base line at a right angle. A height may be outside the polygon. A slanted side is not necessarily the height. Different base-height pairs for the same parallelogram yield the same area.

Original source pair: base 6 with corresponding height 4, and base 5 with corresponding height 4.8, both give 24 square units. Label both perpendicular distances in two drawings. A teacher checks the two different constructions.

5.3 — Generalize the area

Write a rule using symbols b and h to describe a parallelogram’s area, where h is perpendicular to the chosen base. Explain why cutting and rearranging can form a rectangle without changing area. What happens if only the height doubles? What if both dimensions double?

Practice: A 1 m² square contains nine identical small squares; each is cut into two equal triangles. Determine the exact area of six triangles, and the number of these triangles needed to cover 1½ m². Show a fraction model and reasoning.
