Data, Surveys, and Types of Variables

First-party Edulytics learning activity. Numerical examples are precise; student-created diagrams and explanations receive teacher review.

1.1 • Dots of data

Suppose ten students report commute times (in minutes):5,7,8,10,10,12,12,12,15,18. Plot one dot for each student. Label the variable and its units; check that the plot contains exactly ten dots.

1.2 • Survey the class

Ask classmates two questions: one whose answer is a category (favorite breakfast food) and one whose answer is numerical (minutes getting ready). Explain how you chose each and record anonymous counts or measurements.

1.3 • Choose the data type

QuestionData type
How did you get to school?Categorical
How many teachers do you have?Numerical count
What was the last thing you ate?Categorical
How many minutes did you need to get ready?Numerical measurement

Create an original survey question for each type and explain the expected possible answers for teacher review.

Independent Edulytics Cool-down

A survey asks students for their favorite fruit and how many minutes they spend traveling to school. Identify the data type for each question, give example responses and explain which measurement needs a unit.

Teacher rubric: Favorite fruit categorical, commute duration numerical with minutes. Teacher checks appropriate examples and meaningful unit explanation. Automatic Practice checks selected numbers only. Teacher verifies learners' diagrams, scale, annotations, units and verbal justifications separately.
