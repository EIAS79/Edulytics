Interpreting Dot Plots and Typical Values

First-party Edulytics learning activity. Numerical examples are precise; student-created diagrams and explanations receive teacher review.

4.1–4.2 • Read how observations gather

When a dot plot has a cluster, describe what value seems typical. When its dots stretch far apart, describe that as greater spread. These properties are not the same.

4.3 • Homework times

PlotHours rangeAssigned grade from source summary

Match using both center and spread. Source graphs require teacher verification, especially the relationship between a narrow cluster and more similar homework times.

4.4 • An unusually high score

Design a ten-dot basketball-score plot where nine games fall between8 and14, and one score exceeds18. Explain why that game is an outlier and label the points axis.

Independent Edulytics Cool-down

Compare two datasets A=5,5,6,6,7 and B=1,5,6,6,11. Describe a typical value for each and explain which dataset has greater spread.

Teacher rubric: Both have middle/typical6; A range2 and B range10, so B spreads more. Teacher checks plotted dots and contextual explanation. Automatic Practice checks selected numbers only. Teacher verifies learners' diagrams, scale, annotations, units and verbal justifications separately.
