Using an Algorithm to Divide Fractions

First-party Edulytics learning activity. Numerical examples are precise; student-created diagrams and explanations receive teacher review.

11.1 • Build the reciprocal

14/15 divided by7/5 means14/15 multiplied by5/7. Either multiply by5 then divide by7 or use reciprocal in one step. Both give2/3.

11.2 • Critique an error

A student tries4/3÷5/2 and gets10/3 by multiplying by5 and dividing by2. This reverses the reciprocal. The actual quotient is8/15; explain with multiplication and a size estimate.

Independent Edulytics Cool-down

A gardener waters3/4 of a set of plants in1/2hour at a constant rate. How long would watering all plants take? Write division and inverse multiplication.

Teacher rubric: (1/2)/(3/4)=2/3 hour=40minutes. Teacher checks whole set reference and the constant-rate assumption. Automatic Practice checks selected numbers only. Teacher verifies learners' diagrams, scale, annotations, units and verbal justifications separately.
