Solving Fraction Division Word Problems

First-party Edulytics learning activity. Numerical examples are precise; student-created diagrams and explanations receive teacher review.

9.1–9.2 • Decide the unknown

A group shares2½ pounds of berries. If each friend gets1¼pounds, ask how many friends. If five friends share, ask pounds per person. The equation uses the same total but different divisors.

9.4 • Create a situation

Write your own story with a fractional amount and a fractional divisor. State clearly whether the quotient is a group count or size per group. Provide a tape diagram and inverse multiplication check for teacher review.

Independent Edulytics Cool-down

A soap dispenser holds3/4 liter. A refill bottle pours1/8 liter each time. How many complete refills fill the dispenser? Explain with a division and multiplication equation.

Teacher rubric: 3/4÷1/8=6 complete refills,6×1/8=3/4. Teacher checks correct capacity, equal parts and no-spillage assumption. Automatic Practice checks selected numbers only. Teacher verifies learners' diagrams, scale, annotations, units and verbal justifications separately.
