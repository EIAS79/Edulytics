Tables and Double Number Line Diagrams

First-party Edulytics learning activity. Numerical examples are precise; student-created diagrams and explanations receive teacher review.

13.1 • Different representations

A table shows paired quantity values in any row order; a double number line uses distances on parallel axes. Both can represent equal rates.

13.2 • Bread ingredients

Olive oil (tbsp)36915
Garlic (cloves)24610

Draw a double number line for these values. Describe which representation is easier when we add a value of100 batches.

13.3 • Time and travel

72 miles in2 hours means36mph. Create paired rows for1,3 and6½ hours; explain how a table avoids misleading number-line spacing at fractional and very large quantities.
