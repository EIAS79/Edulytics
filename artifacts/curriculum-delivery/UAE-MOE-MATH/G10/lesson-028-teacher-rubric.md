# Grade 10 General U03L04 — original teacher assessment rubric

Source `01متقدم_.pdf` Advanced Arabic 2025–2026 pp48–54, printed31–37. Canonical General ordinal28.

| Criterion | Secure: 2 | Partial: 1 | Incorrect: 0 |
|---|---|---|---|
| Three independent equations | Identifies all three equations and maintains equivalence | One copying slip | Omits an equation |
| Elimination | Eliminates same variable from two independent pairs and solves reduced 2x2 | One algebraic slip | Reduces using the same equation twice |
| Substitution | Reconstructs all three variables from reduced system | One sign slip | Claims solution with unknown variable |
| Independent verification | Substitutes final ordered triple in all three original equations | Checks only two | Checks only one/no checks |
| Rank and geometry | Explains no/unique/infinite intersection of 3 planes accurately | Correct class with weak reasoning | Claims all 3 planes always meet at one point |
| Context and fractions | Units, nonnegativity and exact rational answers handled | One missing interpretation | Rounds noninteger person/count without justification |
