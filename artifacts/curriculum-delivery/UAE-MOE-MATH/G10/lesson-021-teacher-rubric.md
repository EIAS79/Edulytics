| Assessment | 2 — secure | 1 — partial | 0 — incorrect |
|---|---|---|---|
| Extracting square/nth power factors | Finds greatest perfect factor, produces irreducible radicand and correct coefficient | One factor or arithmetic slip | Leaves a perfect factor unextracted |
| Symbolic variable restrictions | Uses √(س²)=|س| and checks even-root real domain | Correct algebra but missing one restriction | Treats negative even root as real |
| Odd nth roots | Handles negative radicands for odd root indices | Correct sign but incomplete explanation | Claims odd root negative is impossible |
| Denominator rationalization | Multiplies numerator and denominator correctly, preserves value and excludes zero | One simplification slip | Changes value or divides by zero |
| Rational vs irrational forms | Identifies perfect square and nonperfect radicals with justification | Correct class but weak proof | Confuses both classes |
| Geometry/measurement and writing | Interprets roots with correct units and independently checks by powering back | Some unit or reasoning omitted | No mathematical basis for result |
