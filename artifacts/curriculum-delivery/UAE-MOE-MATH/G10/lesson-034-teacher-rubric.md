# Grade10 G10-U04-L01 — teacher review rubric for quadratic graphs and technology lab

**Original book:** `01متقدم_.pdf`, Advanced Arabic 2025–2026 Volume1 Unit2 Lesson2-1 physical PDF **112–119**, printed95–102; related data-regression technology LAB PDF121/printed104. PDF120 is unrelated cumulative review and excluded.

| Academic evidence | 2 = complete | 1 = partial | 0 = inaccurate |
|---|---|---|---|
| Quadratic coordinate plot | Correct parabolic shape, axis/vertex, symmetric points and scale, x/y labels | One minor point or scale error | Plot not symmetric or wrong opening |
| Algebraic vertex | Correct h=−b/(2a), k=f(h) with a≠0 | Correct method, one arithmetic slip | Missing leading factor or sign |
| Maximum/minimum and range | Distinguishes a>0 min from a<0 max, uses intended real domain | Direction correct, range not justified | Wrong extremum or omitted domain |
| Intercepts | Correct y-intercept c and x-intercepts when they exist | One algebraic detail missing | Incorrectly treats all parabolas as crossing x-axis |
| Real-world model | Correct feasible input interval, units, economic/physical meaning | Numerical answer without context | Unphysical extension or negative dimensions |
| Technology data regression | Documents table, fits linear/quadratic models, compares residuals and predicts only in justified range | Method sound, weak validation | Treats regression result as certain or manipulates data |
| Explanation | Original written reasoning links each point and symmetry to algebra | Valid result, weak argument | Unjustified graph and incorrect statements |
