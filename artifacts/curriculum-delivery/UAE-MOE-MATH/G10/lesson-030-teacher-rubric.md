# Grade10 General U03L06 — teacher rubric for matrix multiplication

Source Advanced Arabic 2025–2026 Vol1, PDF72–79 printed55–62, technology lab PDF80–81.

| Evidence | Strong (2) | Developing (1) | Incorrect (0) |
|---|---|---|---|
| Size check | Both products checked independently for inner dimensions; outer output rank correct | Minor dimension slip | Illegal multiplication or wrong output order |
| Row×column | Every output entry is an inner product, complete and signed | One multiplication or addition mistake | Entrywise multiplication |
| Noncommutativity | Correctly compares AB and BA and their feasibility | Numeric result only | Assumes AB=BA |
| Identity/distributivity | Demonstrates with compatible matrices | Incomplete justification | Incorrectly changes product order |
| Context | Data row and column labels/units preserved | One label missing | Meaningless cross-label product |
| Calculator/technology lab | Independent hand check validates calculator result | Only calculator result with explanation | Treats output as proof despite wrong dimensions |

Original golden examples: A=[1,2;3,4], B=[5,−1;2,0]; AB=[9,−1;23,−3], BA=[2,6;2,4]. Matrix products of non-square arrays and geometric transformations require teacher review; machine assessment only full-rank 2×2 single target entry and a 0/1 dimension compatibility question, no Stage D testing or routing.
