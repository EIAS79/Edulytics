# Grade10 U04L02 — teacher rubric for graphical roots and graphing calculator

**Original source:** `01متقدم_.pdf`, Arabic Advanced 2025–2026 Volume1 Lesson2-2 PDF122–129/printed105–112, graphing technology lab PDF130/printed113. PDF131 starts next official lesson.

| Goal | Secure 2 | Partial 1 | Incorrect 0 |
|---|---|---|---|
| Graph-to-root | Accurate x-intercepts (y=0) and scaled plot | Minor axis or reading slip | Calls vertex or y-intercept a root |
| Root count | Correct 2 distinct/1 tangent/0 no-real intersections | Root found but multiplicity not explained | Claims every quadratic has two real zeros |
| Estimation | Decimal precision stated and independently f(x)≈0 checked | Good estimate with weak accuracy | Claims approximation is exact |
| Discriminant | Links positive/zero/negative Δ to geometry correctly | Correct count with no explanation | Graph contradicts Δ |
| Calculator lab | Y1=f(x), Y2=0, window and correct intersection(s) | One corrected entry error | Incorrect input or interpreting display |
| Context | Restricts time to t≥0 and labels units | Gets roots but ignores one domain caveat | Accepts negative time as physical |
| Reasoning | Verifies source zero by substitution or equivalent reasoning | Checks only one root | No mathematical verification |

**Original checks:** x²−x−6=0 roots −2 and3; x²−6x+9=0 tangent root3; x²+4x+5=0 has Δ−4, no real root. Lab x²−8x+15=0 intersections 3 and5. Projectile h(t)=−16t²+64t+80 physical landing at 5s, not mathematical −1s.
