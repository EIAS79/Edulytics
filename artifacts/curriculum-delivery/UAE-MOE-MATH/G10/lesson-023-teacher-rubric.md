# Grade10 General G10-U02-L07 — original root-function graph teacher rubric

**Source:** Advanced Unit4 lesson4-3 `01متقدم_.pdf` PDF289–295/printed272–278 and Applied Unit6 lesson6-1 `رياضيات كتاب الطالب تطبيقي 10 8.pdf` PDF170–175/printed353–358, optional technology activity PDF176/printed359.

| Criteria | 2 — secure | 1 — partial | 0 — incorrect |
|---|---|---|---|
| Function domain | Finds correct nonnegative radicand inequality, including √(h−x) cases | One boundary error | Extends root into impossible real negatives |
| Graph point generation | Uses squares and correctly plots 3+ points with labelled axes | One table/scale slip | Arbitrary unverified points |
| Domain/range/starting point | Correct first point and range direction for a and k | Correct starting point but incorrect range | Ignores transformations or signs |
| Transformations | Describes horizontal/vertical shifts, reflection and stretch | One sign inversion | Confuses parent graph with transformed graph |
| Model and inverse relation | Supports square-side context, inverse quadratic restricted to x≥0 | Correct method with one missing assumption | Wrong units or inverse restriction |
| Explanation | Gives mathematical evidence that a plotted point satisfies formula and domain | Incomplete justification | Unsupported sketch |

Original table example: `ص=٢√(س−١)−٣` gives `(١،−٣)`, `(٢،−١)`, `(٥،١)`, domain `س≥١`, range `ص≥−٣`. The new exact numeric assessment covers only computed ordinate at x=h+n² and lower-bound domain x≥h.
