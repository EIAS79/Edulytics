# U01:L01 original seven How To procedures and four explanatory notes

Sources: local original OpenStax 2017 PDF pp. 19,21–23,25,26,29,31. No additional source research or third-party reuse.

1. PDF p.19, Determine whether a relation is a function. Independent method: Identify inputs and outputs; check whether any input is associated with conflicting values.
2. PDF p.22, Classify a tabulated input-output mapping. Independent method: Check each displayed input; duplicates are allowed only when their outputs agree.
3. PDF p.23, Evaluate a formula-defined function. Independent method: Substitute the complete requested input and simplify correctly, respecting restrictions.
4. PDF p.25, Express an implicit relation as explicit output formula if possible. Independent method: Isolate the output variable; record domain and any multiple branches.
5. PDF p.26, Evaluate and invert a finite table. Independent method: Find the input column and read its output; for inverse lookup return all listed inputs matching the output.
6. PDF p.29, Use the vertical-line test on a graph. Independent method: Try vertical lines over the domain; any line hitting distinct graph outputs twice disproves a function.
7. PDF p.31, Use the horizontal-line test on a function. Independent method: For a function, a repeated output at distinct inputs violates one-to-one status.
